## 모바일 청첩장을 직접 만들게 된 계기

결혼을 준비하면서 모바일 청첩장 서비스를 알아봤는데, 대부분 유료이고 커스터마이징에 한계가 있었다. 개발자인데 직접 만들어보면 어떨까 싶었지만, 프론트엔드 작업을 처음부터 하자니 시간이 부담됐다.

그래서 **Claude AI**에게 코드 작성을 맡기고, **AWS S3** 정적 호스팅으로 배포하는 방식을 선택했다.

## 기술 스택

| 구분 | 사용 기술 |
|------|-----------|
| 코드 작성 | Claude AI |
| 호스팅 | AWS S3 (정적 웹사이트 호스팅) |
| 프론트엔드 | HTML, CSS, JavaScript |

## Claude AI로 코드 작성하기

Claude에게 원하는 청첩장의 구성 요소를 알려주고 코드를 생성했다.

### 프롬프트 예시

```
모바일 청첩장 웹페이지를 만들어줘.
- 메인 사진과 인사말
- 예식 일시, 장소 안내
- 카카오맵 연동
- 갤러리
- 카카오페이 축의금 버튼
- 참석 여부 RSVP
```

Claude가 HTML/CSS/JS 코드를 한 번에 생성해줬고, 수정이 필요한 부분은 대화를 이어가며 바로 반영할 수 있었다. 디자인 수정, 애니메이션 추가, 반응형 레이아웃 조정 등 세부적인 요청도 잘 처리해줬다.

## AWS S3로 배포하기

### 1. S3 버킷 생성

```bash
aws s3 mb s3://my-wedding-invitation
```

### 2. 정적 웹사이트 호스팅 설정

S3 버킷 속성에서 정적 웹사이트 호스팅을 활성화하고, 인덱스 문서를 `index.html`로 설정한다.

### 3. 파일 업로드

```bash
aws s3 sync ./ s3://my-wedding-invitation --acl public-read
```

### 4. 버킷 정책 설정

퍼블릭 접근을 위한 버킷 정책을 추가한다.

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::my-wedding-invitation/*"
    }
  ]
}
```

배포 후 S3에서 제공하는 엔드포인트 URL로 바로 접근할 수 있다.

## 느낀 점

- **비용 절감**: 모바일 청첩장 서비스 비용(보통 3~5만원)을 아낄 수 있었다. S3 호스팅 비용은 거의 무료에 가깝다. AWS 계정을 생성하면 6개월간 쓸수있는 $200 크레딧을 준다 이것을 사용하면 무료로 사용이 가능하다.
- **자유로운 커스터마이징**: 원하는 디자인과 기능을 제한 없이 넣을 수 있었다.
- **Claude AI의 생산성**: 프론트엔드에 익숙하지 않아도 대화만으로 원하는 결과물을 빠르게 만들 수 있었다. 수정 요청도 자연어로 하면 되니까 개발 속도가 확실히 빨랐다.

직접 만든 청첩장으로 지인들에게 공유했을 때 반응이 좋았다. 개발자라면 한 번쯤 도전해볼 만한 사이드 프로젝트다.
